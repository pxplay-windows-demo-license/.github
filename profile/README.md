## Windows Build Evaluation Overview

## Getting Started Playbook

Get the Windows portable package and extract the full archive into a dedicated folder. Put the Windows PC and PS5 on the same network, enable Remote Play on the console, and open Pair Device to generate a code. In PXPlay, select your console type, enter the code and follow the app's PlayStation account prompts.

Start with Local Connect and verify that the sticks, triggers, picture and audio work. Adjust only one video setting at a time and note the combination that stays stable. When you move to the full build, install it into a separate folder instead of overwriting the portable one.

## Everyday Use

Open the app, select the intended console profile, and attach your gamepad before starting the stream. If the PlayStation login flow appears, use the account that matches the console profile. Use features such as button mapping or frame pacing only if you have a specific problem to solve. Keep a note of your working decoder, renderer and bitrate for the next driver or app update.

## Practical Scenarios

Scenario A - Portable check: Confirm the controller, sound and picture on the exact Windows device you plan to use.  
Scenario B - New PC: Move the full desktop package to the new machine instead of re-extracting the portable build.  
Scenario C - Mixed folders: Keep the portable and full builds apart so an update to one does not overwrite the other.  
Scenario D - Wi-Fi stutter: Compare the same stream with the console on Ethernet before changing graphics settings.

## Troubleshooting Common Issues

Install issues? Extract the entire portable ZIP to a local folder and confirm that you selected the Windows package.  
Performance problems? Start with a lower resolution or bitrate, then compare the available decoder options on the same network.  
Edition differences? The portable and full builds are separate files; move to the full build once the portable one works.
Compatibility? Check Windows and GPU driver support, then verify the gamepad in the portable build first.  
Update failures? Note your working settings, check StreamingDV's desktop release notes, and reinstall or re-extract the matching official build.
